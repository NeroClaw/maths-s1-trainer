# Maths S1 · BTS SIO

Trainer interactif pour réviser les maths du BTS blanc (programme S1).

- 5 chapitres : arithmétique, numération, matrices, propositions, ensembles
- Fiche essentielle, pièges classiques, cartes de rappel actif
- Calculateurs : PGCD/PPCM, conversion de bases, complément à 2, déterminant, inverse, table de vérité, cardinaux
- Quiz avec score et progression sauvegardée en local
- Mémo imprimable (bouton Imprimer / PDF)

Site statique, un seul fichier `index.html`, aucune dépendance de build.
